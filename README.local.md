## First creating and pushing
```bash
git init
git add README.md
git commit -m "commits"
git branch -M main
git remote add origin https://github.com/KhaledMahmudKM/bookengine.git
git push -u origin main
```
# Then add all the files
```bash
git add *
git commit -m "more commits"
git push -u origin main
```
